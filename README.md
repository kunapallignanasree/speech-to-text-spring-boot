# Speech to Text Spring Boot Application

A Spring Boot application that integrates with OpenAI's Whisper API to transcribe audio files into text, storing transcription history with full CRUD capabilities.

## Tech Stack
* **Java 17** & **Spring Boot**
* **Spring Data JPA** & **Hibernate**
* **MySQL / PostgreSQL**
* **Docker**
* **OpenAI Whisper API**

## Features
* Transcribe audio files to text.
* Save, retrieve, update, and delete transcription logs (CRUD).
* Persistent database storage.
* RESTful API endpoints.
